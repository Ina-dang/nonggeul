# 농글 (Nonggeul)

농업현장에서 토마토 상태를 확인하도록 돕는 서비스를 개발합니다.

## 현재 단계

찰토마토 열매 하나가 중심으로 보이는 사진을 대상으로,
착색 상태를 세 단계로 분류할 수 있는지 확인하는 PoC를 진행합니다.

- 미착색
- 착색 진행
- 충분히 착색

분류 결과는 실제 정답이나 수확 적기로 단정하지 않습니다.

## 프로젝트 구조

- `frontend/`: 농장주 화면
- `backend/`: 계정, 결과 기록, 알림
- `ml/`: 데이터 준비, 모델 학습, 평가
- `device/`: 장치 촬영, 분석, 전송, 이동 연동
